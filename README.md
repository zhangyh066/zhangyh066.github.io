# Julian Zhang · 个人主页

金融科技、数据工程与轻量模型主题的个人主页。以暖纸色、手绘物件和研究档案式排版呈现，默认英文，可切换中文。

## 在线访问

**https://zhangyh066.github.io/**

源代码仓库：https://github.com/zhangyh066/zhangyh066.github.io

## 本地预览

无需安装依赖，在本目录运行：

```bash
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。

## 页面内容

- 个人介绍与金融科技方向硕士教育信息
- 实习与研究经历
- 四个开源项目
- 工具与技能
- 推荐论文阅读清单

## 技术

- 原生 HTML、CSS、JavaScript，无构建步骤
- 原创 SVG 手绘插画与首屏落笔动画
- 中英文切换与响应式布局，支持减少动态效果
- GitHub Pages：`main` 分支根目录，静态发布

## 文件

- `index.html`：个人资料、项目与中英文内容
- `styles.css`：配色、排版与动效
- `script.js`：语言切换、移动导航与入场交互
- `assets/`：头像与网站图标
