# 张宇辉的个人主页

金融数据、AI 与产业链主题的静态个人主页，包含定制数据研究所插画、滚动视差、中英文切换和深浅色模式。

## 在线访问

**https://zhangyh066.github.io/**

源代码仓库：https://github.com/zhangyh066/zhangyh066.github.io

## 本地预览

无需安装依赖，在本目录运行：

```bash
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。

## 技术

- 原生 HTML、CSS、JavaScript
- SVG 建筑插画与响应式布局
- GitHub Pages：`main` 分支根目录，静态发布

## 文件

- `index.html`：个人资料与项目内容
- `styles.css`：配色、布局与动效
- `script.js`：语言、主题与滚动交互
- `assets/`：头像、建筑插画与网站图标

视觉风格参考 [0z5a.github.io](https://0z5a.github.io/)，页面插画与实现为本项目定制。
